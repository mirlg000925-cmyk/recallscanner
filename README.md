# 리콜스캐너 (RecallScanner)

차종 또는 차종+연식을 입력하면 공개된 자동차 리콜 정보를 확인할 수 있는 무료 웹서비스입니다.
Next.js(App Router) + TypeScript + Tailwind CSS로 제작되었고, 별도 데이터베이스 없이 정적/서버
렌더링으로 동작해서 Vercel 무료 플랜에 그대로 배포할 수 있습니다.

## 이번 버전에서 구현된 것 (핵심 기능)

- 홈페이지 검색창 + 인기 차종 목록
- 검색어 자동 인식: 공백/대소문자 정규화, 오타·별칭·영문 매칭, 레벤슈타인 유사도 기반 후보 제시
- "차종 + 연식" 형태 검색 (`팰리세이드 2022`, `쏘나타 22년식` 등) 및 연도 자동 추출
- 검색 결과가 애매할 때 "혹시 이 차종을 찾으시나요?" / 비슷한 차종 후보 제시 UI
- 차종별 SEO 페이지 `/recall/[제조사]/[차종]`
- 연식별 SEO 페이지 `/recall/[제조사]/[차종]/[연식]` (실제 데이터가 있는 연식만 생성)
- 리콜 카드: 리콜 실시일 · 대상 · 결함 내용 · 발생 가능 문제 · 조치 방법 · 대상 대수 · 공식 출처 ·
  최근 업데이트일
- "🟡 관련 리콜 있음" 표기 + 공식 자동차리콜센터(car.go.kr) 연결 버튼 (차량번호는 저장하지 않음)
- sitemap.xml / robots.txt 자동 생성
- 차량용품(쿠팡 파트너스) 추천 영역 placeholder
- 회원가입/로그인/결제 없음

## 이번 버전에서 만들지 않은 것 (다음 단계)

PRD 기준 "핵심 기능 우선"으로 범위를 잡아서, 아래 항목은 이번 버전에 포함되지 않았습니다.

- 관리자 페이지 (차종/리콜/검색어 별칭 관리 화면)
- 데이터 자동 수집·업데이트 스케줄러 (매일 1회 자동 갱신)
- 차량번호/차대번호 기반 실제 리콜 대상 자동 판정
- 공식 데이터 API 연동 (아래 "데이터 출처" 항목 참고)

## 데이터 출처와 현재 한계 (중요)

자동차리콜센터(car.go.kr)는 검색 결과가 자바스크립트로 렌더링되고, 상세페이지는 자동화된
요청을 막고 있어(405 응답) 이번 세션에서 직접 크롤링할 수 없었습니다. 그래서 데이터는 두
경로를 함께 쓰고 있습니다.

**1) 한국교통안전공단이 공공데이터포털에 올린 파일데이터 (지금 실제로 쓰고 있는 데이터)**

국토교통부 오픈API(`15089863`)는 활용신청 화면에서 담당부서·사이트·서버명을 요구합니다 —
이건 사실 기업/기관용 **오픈API 운영계정** 신청에 붙는 항목이라, 개인이 취미로 만드는
서비스에는 맞지 않는 절차입니다. 대신 같은 기관이 공개한 **"한국교통안전공단_자동차결함
리콜현황"** 파일데이터는 로그인만 하면 별도 신청 없이 바로 내려받을 수 있고, 이용허락범위
제한도 없습니다.
- 데이터셋 페이지: https://www.data.go.kr/data/3048950/fileData.do
- 이번에 반영한 파일: `data/recalls-2025-raw.csv` (2025-12-31 기준, 2025년 한 해 리콜
  1,045건, 48개 제작사)
- 제공 항목: 제작자·차명·생산기간(부터/까지)·리콜개시일·리콜사유. (대상 대수와 조치방법은
  이 파일에 없어서, 조치방법은 "공식 출처에서 확인" 안내 문구로 대체했습니다.)
- `팰리세이드/아반떼/싼타페/쏘렌토/카니발/GV80/BMW 520d/테슬라 Model 3` 8개 차종에 대해
  이 파일에서 실제로 매칭되는 행을 찾아 리콜 11건을 자동으로 정리해 넣었습니다. 같은
  리콜사유·리콜개시일을 공유하는 트림(예: 520d / 520d xDrive)은 하나의 리콜로 묶었고,
  **연식별 페이지는 이 파일의 실제 생산기간을 그대로 반영**했습니다 (예: BMW 520d는
  2010~2020년형 페이지가 자동 생성됩니다 — 뉴스 기반 추정이 아니라 정부 데이터 원본입니다).
  차종 추가/갱신은 `scripts/build-official-recalls.py`로 반자동화해뒀습니다.
2. **국토교통부 발표를 인용한 언론 보도 10건**은 이 CSV가 2025년치만 담고 있어서 빠지는
   2020~2024년 리콜(예: BMW 520d EGR쿨러, 팰리세이드 전동시트 등)을 보완하기 위해 그대로
   남겨뒀습니다. 각 카드 하단의 "공식 출처" 링크로 원문을 확인할 수 있습니다.
3. **국산 차종 커버리지 확대**: 위 8개 차종 외에도 현대·기아·제네시스·쉐보레·르노코리아·
   KG모빌리티 소속으로 2025년 CSV에 리콜 이력이 있는 차종 37개(포터, 스타리아, 투싼,
   스포티지, 코란도, 니로, EV3/EV4/EV9, GV60/GV70, 카니발 하이브리드 등)를 추가로 정리해
   총 54개 차종 / 76건의 리콜 데이터를 담고 있습니다. 레이·스파크·모닝·K5·K8·그랜저·캐스퍼
   (내연기관)처럼 이 CSV 기준으로 2025년에 리콜이 없었던 인기 차종도 검색은 되도록 차종
   정보만 등록해뒀고("현재 등록된 리콜 없음"으로 표시), 실제 리콜이 생기면 같은 스크립트로
   채울 수 있습니다.

결과적으로 지금 인기 차종 대부분은 검색 시 실제 페이지로 연결되며, 리콜 이력이 있는
차종은 정부 데이터 기준 리콜 건수가 그대로 표시되고, 이력이 없는 차종은 "현재 데이터베이스에
등록된 공개 리콜 정보가 없습니다"라는 안내와 함께 공식 리콜센터 링크가 노출됩니다.

**더 많은 차종으로 넓히려면**, `data/recalls-2025-raw.csv`는 이미 48개 제작사 데이터를
전부 담고 있으니 `scripts/build-official-recalls.py`의 `TARGETS`에 원하는 차종의 검색
키워드만 추가하고 다시 실행하면 됩니다 — API 신청 없이 바로 확장할 수 있습니다. 매년
새 CSV가 올라오면 같은 스크립트로 갱신하면 되고, 이걸 관리자 페이지나 자동 배치로
옮기는 것이 다음 단계입니다.

## Vercel로 배포하기 (무료, 약 5분)

> 참고: Claude가 이 계정 환경에서 Vercel CLI로 직접 배포를 시도해봤는데, 조직 차원의
> 네트워크 정책으로 `vercel.com`/`api.vercel.com` 접속 자체가 막혀 있어서(클라우드
> 환경뿐 아니라 연결된 컴퓨터에서도 동일하게 차단됨) 자동 배포는 불가능했습니다. 아래
> 단계는 그 대신 본인 브라우저로 직접 진행하는 방법이며, 실제로는 클릭 몇 번이면
> 끝나는 짧은 과정입니다.

1. GitHub에 이 프로젝트를 올립니다.
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 리콜스캐너 MVP"
   git branch -M main
   git remote add origin <본인의 GitHub 저장소 URL>
   git push -u origin main
   ```
2. https://vercel.com 에 접속해 GitHub 계정으로 로그인합니다.
3. "Add New… → Project"를 누르고 방금 올린 저장소를 선택합니다.
4. 프레임워크는 Next.js로 자동 인식됩니다. 별도 설정 없이 "Deploy"를 누르면 됩니다.
5. 환경변수(선택): 도메인이 정해졌다면 Project Settings → Environment Variables에
   `NEXT_PUBLIC_SITE_URL=https://내도메인.com` 을 추가하면 sitemap.xml과 메타태그에
   정확한 주소가 반영됩니다. (설정하지 않아도 배포/동작에는 문제 없습니다.)
6. 배포가 끝나면 `*.vercel.app` 주소가 생성되고, 이후 GitHub main 브랜치에 푸시할 때마다
   자동으로 재배포됩니다. Project Settings → Domains에서 보유하신 도메인을 연결할 수 있습니다.

## 쿠팡 파트너스 연결하기

`components/ShoppingSection.tsx`에 있는 링크는 현재 제휴 태그가 없는 일반 검색 링크입니다.
쿠팡 파트너스(https://partners.coupang.com) 가입 후 발급되는 본인의 파트너스 링크로
`href` 값을 교체하면 됩니다. 쿠팡 정책상 "이 포스팅은 쿠팡 파트너스 활동의 일환으로,
이에 따른 일정액의 수수료를 제공받습니다" 문구를 반드시 노출해야 하며, 해당 문구는 이미
컴포넌트에 포함되어 있습니다.

## 데이터 추가/수정하기

- 차종 추가: `lib/vehicles.ts`
- 리콜 추가: `lib/recalls.ts` (각 리콜은 `vehicleSlugs`로 `제조사slug/차종slug` 형식을 통해
  차종과 연결됩니다)
- 검색어 별칭 추가: 해당 차종의 `aliases` 배열에 오타/영문/축약형을 추가하면 됩니다.

```

  recall/[manufacturer]/[model]/[year]/ 연식 SEO 페이지

components/                             검색창, 리콜 카드, 헤더/푸터 등 UI

  vehicles.ts                           차종 데이터
  recalls.ts                            리콜 데이터
  search.ts                             검색어 정규화/유사도 매칭 로직
```
